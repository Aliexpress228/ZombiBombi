**ZombiBombi** — это мой старый детский мини-проект, который я нашел спустя 7 лет и решил вдохнуть в него новую жизнь. Игра была полностью переписана, собрав в себе современные механики и получив поддержку standalone-запуска (без необходимости устанавливать среду разработки).

Теперь это полноценный аркадный экшен, где вам предстоит передвигаться по лабиринту, ставить бомбы и расчищать путь!

---

## 🚀 Скачать и играть
Вам не нужно ничего компилировать или настраивать. Готовая версия игры уже собрана!
1. Перейдите в раздел **[Releases](../../releases)** справа на этой странице.
2. Скачайте последний `.zip` архив.
3. Распакуйте в любую папку и запустите `ZombiBombi.exe`.

---

## 🕹 Управление
Игра управляется с клавиатуры и мыши:

| Клавиша / Кнопка | Действие |
| :--- | :--- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Движение персонажа |
| 🖱 **ЛКМ** (Левая кнопка мыши) | Поставить бомбу |
| <kbd>Space</kbd> (Пробел) | Взорвать все поставленные бомбы |
| <kbd>Enter</kbd> | Показать счет (когда закончатся бомбы) |
| <kbd>Esc</kbd> | Выход из игры |

## 🛠 Для разработчиков (Сборка из исходников)

Если вы хотите заглянуть под капот, изменить карту или механику — проект полностью открыт.

### Зависимости и библиотеки
* **Язык:** C++ (стандарт C++14)
* **Графика и ввод:** [TXLib (ТХ Library)](https://www.ctorial.ru/txlib/) — простая графическая библиотека для обучения программированию на C++.
* **Система сборки:** CMake (3.15+)
* **Среда разработки:** Visual Studio (MSVC) или любая другая IDE с поддержкой CMake.
